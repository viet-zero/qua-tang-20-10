QUÀ TẶNG WEB 20/10 💗

1. Mở index.html bằng Chrome để xem thử ngay trên máy.
2. Để người yêu quét QR mở được từ điện thoại, bạn cần đưa web lên Internet:
   - Cách đơn giản: tạo repository GitHub mới, tải index.html lên.
   - Vào Settings → Pages → Deploy from a branch → chọn branch main và folder /(root) → Save.
   - Chờ GitHub Pages tạo đường dẫn dạng https://TEN-GITHUB.github.io/TEN-REPO/
3. Dùng đường dẫn đó tạo mã QR bằng công cụ tạo QR bạn tin tưởng, rồi gửi/in mã QR.
   Lưu ý: QR chỉ hoạt động ở mọi nơi khi website đã được publish công khai; đường dẫn file trên máy không dùng được.
4. Muốn cá nhân hóa, mở index.html và sửa tiêu đề, lời chúc, hoặc danh sách `phrases`.

Web tự co giãn trên điện thoại, có nền sao lấp lánh, lời yêu thương bay nhấp nháy và trái tim lớn đập ở giữa.
Không cần cài thư viện hoặc máy chủ.
